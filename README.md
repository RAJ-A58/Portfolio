# Raj Patil | Software Engineer Portfolio

Personal portfolio of Raj Patil, focused on intelligent systems, compilers, and machine learning.

**Live site:** [rajlp-portfolio.vercel.app](https://rajlp-portfolio.vercel.app/)

## Stack

- React 18
- Vite 5
- Three.js / React Three Fiber
- Vanilla CSS

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
